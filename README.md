# Aman Kaurav — personal portfolio

A dark, technical personal site built with React + Vite. The UI direction takes cues from the resources : shadcn/ui, Magic UI, Aceternity UI and Spline.

## Run

```bash
npm install
npm run dev
```

Then open the local URL Vite prints.

## Customize before publishing

- Replace `https://github.com/` and `https://www.linkedin.com/` with your real profiles.
- Replace `hello@example.com` with your email.
- Replace `#` project links with actual GitHub/live-demo URLs.
- Add your real project screenshots later.

## Design notes

- shadcn-style source-owned UI patterns: cards/buttons
- Magic UI-inspired spotlight/magic card treatment
- Aceternity-inspired visual effects and dark experimental aesthetic
- Spline can be added later if you have a Spline scene URL; no fake scene is embedded here.
